# 📚 3rd-Sem ECE - Data Structures Lab Solutions

Welcome to the **open-source repository** for **Data Structures Lab (3rd Semester - ECE)**.  
This repo contains well-organized **C program solutions** for all lab assignments and practice questions — made for students, by a student.  

Feel free to fork, star ⭐, or contribute!

---

# Important for lab exam

* Find largest & smallest element from an array. 
* Insert an element & delete an element at any position in an array. 
* Insertion Sort, Selection Sort, Bubble Sort, Merge Sort, Quick Sort, Linear Search, Recursive Binary Search. 
* Sparse matrix representation in 3-tuple format 
* Implement stack operations (push, pop, peek, display) 
* Implement linear queue, circular queue operations (enqueue, dequeue, display) 
* Implement stack & queue using linked list 
* Evaluate postfix expression. 
* Convert infix expression to postfix expression. 
* Insert and delete operations on a singly linked list at a) beginning b) end c) at any position 
* Insert and delete operations on a doubly linked list at a) beginning b) end c) at any position 
* Create a doubly linked list and display it in reverse order. 
* Create a circular linked list and display it. 
* Search a key element in a singly linked list. 
* Reverse a string using stack. 
* Multiply two matrices 
* Check whether a matrix is symmetric or not.
